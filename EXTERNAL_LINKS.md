# External learning links on iPhone

Ordo retains its standalone installation and all existing progress storage. External HTTPS links are delegated to Safari when the app is running in iOS standalone mode, using a best-effort Safari URL scheme (not an Apple-documented web API). If the scheme is unsupported, use the normal HTTPS link or copy it into Safari. The preference in More → Resources → Website sign-ins & Safari can be disabled. Desktop and normal browser navigation, internal links, downloads, and App Store links are unchanged. No credentials, cookies or tokens are read, stored or transmitted by Ordo. Websites decide login expiration. Test on an actual iPhone after deployment. Apple documents separate standalone cookies: https://developer.apple.com/videos/play/wwdc2023/10120/ .
